# RunningTools

## Idea
C'est un projet qui permet aux coureurs de calculer rapidement et facilement différentes allures bien utiles à l'entraînement
- Convertir km/h en min/km ?
- Calculer un temps de passage au 5km, si on veut faire 3h sur un marathon ?
- Calculer à quelle allure aller si je veux courir à 85% de ma VMA ?

runningtools.fr répond à tous ces problèmes !

## Lancement en local
To run the project with jetbrain tools : 

`npm run dev` (or go in `package.json` and run the script `"dev": "vite"`).

To have debug mode, click on the URL in terminal with `ctrl` + `maj` + `click`. 
After that, breakpoint will work

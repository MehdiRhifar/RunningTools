# RunningTools
 
To run the project with jetbrain tools : 

`npm run dev` (or go in `package.json` and run the script `"dev": "vite"`).

To have debug mode, click on the URL in terminal with `ctrl` + `maj` + `click`. 
After that, breakpoint will work
